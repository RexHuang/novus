Why Novus

Evolves itself — for real

Finds bugs in its own source, patches its own TypeScript, runs the test suite, and ships the rebuild to every machine in its fleet. Not a marketing word — a reproducible loop with git history as evidence.
读改自身源码 → 编译测试 → 自主部署到全部节点，git 历史即证据。

Phone-first architecture

The lightest device carries the brain. Novus lives on an Android phone (Termux) and commands servers over a single WebSocket — personal AI infrastructure at the cost of an old phone.
手机承载大脑与记忆，服务器只是双手。

Tiny, hackable core

~15K lines of TypeScript, zero heavyweight SDKs, zero-config dynamic tool registry. Any Anthropic-protocol endpoint works — Anthropic, DeepSeek, Zhipu GLM, Moonshot Kimi, OpenRouter, local servers.
极小内核，双轨环境变量，国产大模型开箱即用。

Quickstart — 5 minutes

# any machine with Node.js — including Android Termux
git clone https://github.com/RexHuang/novus.git && cd novus
npm install && npm run build

# point it at any Anthropic-protocol API (or reuse ANTHROPIC_* vars)
export NOVUS_BASE_URL="https://api.anthropic.com"
export NOVUS_AUTH_TOKEN="sk-..."
export NOVUS_MODEL="claude-sonnet-4-20250514"

npm link                # register the `novus` command
novus                   # interactive chat
novus --serve --port 24999   # HTTP API + web UI

Android: install Termux from F-Droid, then pkg install nodejs-lts git python make clang — full guide in MOBILE.md. Works out of the box with Anthropic, DeepSeek, Zhipu GLM, Moonshot Kimi, OpenRouter, LiteLLM gateways and local servers.
